# Najm — Accessible Website

Static Arabic (RTL) website built with HTML, Tailwind CSS (CDN) and vanilla JavaScript from the Najm Figma designs, with a built-in accessibility tool.

## Pages

- `index.html` — home page
- `login.html` — login
- `register.html` — create account

## Features

- **Accessibility tool** (header button «إمكانية الوصول»): light / dark / automatic theme, text size, high contrast, text spacing, link highlighting, reduced motion, colour-blindness correction, built-in Arabic screen reader and voice control.
- **Responsive**: the Figma desktop layout from 1280px up; tablet and phone layouts below 1280px (`css/responsive.css`).
- **Forms**: client-side validation with accessible error messages (`js/forms.js`). There is no backend yet.

## Editing

The header (main menu) and footer are shared by every page. Edit the sources in `src/`, then rebuild:

```bash
node src/build.js
```

- `src/partials/` — shared `<head>`, header, footer and scripts
- `src/pages/` — each page's own content

Do not edit `index.html`, `login.html` or `register.html` directly; they are regenerated by the build.

## Running locally

Serve the folder with any static file server, for example:

```bash
npx serve .
```
